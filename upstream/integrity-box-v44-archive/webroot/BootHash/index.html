You can obtain the boot hash from a Key Attestation app or from a root detector that reports abnormal verified boot hash behaviour.

The Auto Get Hash from TEEsim option allows Integrity Box to automatically retrieve the verified boot hash generated by the TEEsim module (on every reboot), so you do not need to manually find and paste the hash yourself. Once enabled, Integrity Box will wait for TEEsim to generate the required boot hash and then retrieve it automatically for use by the module. This feature only works when TEEsim is installed, enabled, and functioning correctly on your device; if TEEsim is not installed or has been disabled, Integrity Box will not be able to retrieve the hash automatically.
