Usage
priority_high
Choose your primary root
Select the root solution you actually intend to use on your device. This is useful when your ROM ships with KernelSU by default but you prefer to use Magisk or APatch as your actual root solution.
hub
Resolve root conflicts
Some modules detect more than one root implementation and cannot reliably determine which environment should be treated as primary. This tool lets you explicitly identify whether Magisk or APatch is the root solution you want them to recognize.
warning
When should you use it?
Use it when your ROM ships with KernelSU but you intentionally use Magisk or APatch instead, or when the bundled KernelSU version is too old and you need another root solution.
