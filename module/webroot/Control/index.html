help_outlineWhat does this do?

Core Settings
tune
Zygiskless Mode
Enable this if you are on a Pixel stock ROM or a ROM with built-in Play Integrity spoofing. It disables Zygisk-based injection to avoid conflicts.
developer_mode
Zygote Debugging
Enables verbose logging inside the module. Only use for debugging. Many banking and streaming apps detect verbose logs and may refuse to launch. You should not enabled this toggle unless you're reporting a bug.
health_and_safety
Safe Mode
This prevents custom-ROM-specific features from being used on stock firmware, where they may cause compatibility issues or unexpected behavior. YOU SHOULD NOT disable this if you're using STOCK ROM
bolt
Agressive Mode
Enabling this forces every prop to be set to its correct value, whether it already exists or not. Disabling it only modifies props that already exist on your device and skips non-existing props by default.
Tools & Utility
update
Sync with Canary
Enables seamless, independent updates for language packs and hotfix patches without requiring a module upgrade or device reboot.
memory
Customize ZN
You should enable this if you're using ZygiskNext. It automatically configured the best setup for your apps & modules by tweaking memory type, linker hooks, and denylist enforcement.
developer_board
Extract Boot.img
Extracts the active boot image from your device for backup or manual patching purposes. Output is saved to /sdcard/BootImages.
published_with_changes
Inject HMA-OOS config
Injects the pre-configured Hide My Applist (OOS variant) config for bundled app hiding. Click this button if HMA OOS module is installed
